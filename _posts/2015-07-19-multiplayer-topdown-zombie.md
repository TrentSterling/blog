This is a photon networked topdown twinstick shooter that I plan to release on PC/Android. Preliminary testing shows that the game will run smoothly on the Fire Phone and the FireTV with shadows disabled.

I'm hoping to get this game out quickly as all the artwork has been purchased from the asset store. I need to work on a lot of UI stuff (ugh, don't I need that for all my games?)

I'm hoping to use very simple minimal colored rectangle UIs for this game, and all my future games. If I can get a generic UI framework built, perhaps I can prototype these games a lot faster.
