Dash Till Dawn is a 1 button endless runner type game developed by me and 2DGameDev ([twitch](http://www.twitch.tv/2dgamedev)).

2DGameDev did all the art, and I took care of the programming.

The game is currently playable, but we’re still polishing the game up and adding menus. It should be our first release on Android.
